# Job Description Analysis — CSE Curriculum Audit

**Programme:** B.Tech Computer Science and Engineering  
**Institution:** ICFAI Foundation for Higher Education, Hyderabad  
**Admission batch:** 2023–2027  
**Analysis date:** 23 October 2026

## 1. Objective

This analysis compares three published job descriptions with the skills developed through a Computer Science and Engineering curriculum. The aim is to identify relevant strengths and potential curriculum improvements, not to claim that employers require every proposed change.

## 2. Job Description 1 — HCLTech

- **Role listed on the careers portal:** Analyst (Support & Operations)
- **Job title in the description:** Analyst — Generative AI
- **Experience:** 0–3 years, including fresh graduates
- **Locations listed:** Noida, Hyderabad, Chennai, Bengaluru and Pune
- **Official source:** https://careers.hcltech.com/job/Analyst-Support--Operations/166721-en_US/
- **Access date recorded in the original draft:** 23 October 2026

### Skills and responsibilities identified

- Python programming for generative AI use cases.
- Hands-on AI/ML or LLM application projects through academics, internships or independent work.
- Familiarity with deep learning, NLP, LLMs or image-processing techniques.
- Development of AI agents using LangGraph, LangChain and Python on cloud AI platforms.
- Data collection and preprocessing for model training, evaluation and deployment.
- Model optimisation, documentation and collaboration with team members.

### Curriculum implications

The curriculum should provide opportunities to apply Python, NLP and deep learning in working projects. Students could benefit from practical experience evaluating AI outputs, documenting experiments and deploying small applications.

## 3. Job Description 2 — Accenture

- **Experience:** Graduate-level role; the original draft records 0–1 year of experience. Recheck the live listing before submission.
- **Official source:** https://www.accenture.com/in-en/careers/jobdetails?id=AIOC-S01665346_en
- **Access date recorded in the original draft:** 23 October 2026

### Skills and responsibilities identified in the original analysis

- Python programming and object-oriented programming.
- Data structures and algorithms.
- SQL and database concepts.
- REST APIs and Git version control.

## 4. Job Description 3 — Google

- **Location recorded in the original analysis:** Hyderabad, India
- **Experience requirement recorded in the original draft:** At least one year of software-development experience and one year of experience with data structures and algorithms.

### Skills and responsibilities identified in the original analysis

- Programming in languages such as Python, C, C++, Java or JavaScript.
- Data structures and algorithms.
- Experience in machine learning, AI algorithms, AI platforms or generative AI agents.

**Verification note:** Recheck the live listing for its current title, location and experience requirements. The details above are based on the original analysis and should not be treated as newly verified facts.
