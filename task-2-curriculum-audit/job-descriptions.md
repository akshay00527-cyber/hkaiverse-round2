# Job Description Analysis — CSE Curriculum Audit

**Programme:** B.Tech Computer Science and Engineering  
**Institution:** ICFAI Foundation for Higher Education, Hyderabad  
**Admission batch:** 2023–2027  
**Analysis date:** 23 October 2026

## 1. Objective

This analysis compares three published job descriptions with the skills developed through a Computer Science and Engineering curriculum. The aim is to identify relevant strengths and potential curriculum improvements, not to claim that employers require every proposed change.

## 2. Job Description 1 — HCLTech

- **Role:** Analyst — Generative AI
- **Experience:** Listing states 0–3 years, including fresh graduates.
- **Official source:** https://careers.hcltech.com/job/Analyst-%28Support-%26-Operations%29/167242-en_US/
- **Access date:** 23 October 2026

### Skills and responsibilities identified

- Python programming for generative AI use cases.
- Hands-on academic, internship, or independent AI/ML projects.
- Familiarity with NLP, computer vision, deep learning, and LLM-based applications.
- Data processing and problem-solving.
- Familiarity with frameworks and tools such as LangChain, LangGraph, and MLOps practices.

### Curriculum implications

The curriculum should provide opportunities to apply Python, NLP, computer vision, and deep learning in working projects. Students could benefit from practical experience evaluating AI outputs, documenting experiments, and deploying small applications.

## 3. Job Description 2 — Accenture

- **Role:** AI/ML Computational Science Associate
- **Experience:** The listing describes a graduate-level role with 0–1 year of experience.
- **Official source:** https://www.accenture.com/in-en/careers/jobdetails?id=AIOC-S01665346_en
- **Access date:** 23 October 2026

### Skills and responsibilities identified

- Python programming and object-oriented programming.
- Data structures and algorithms.
- SQL and database concepts.
- REST APIs and Git version control.
- Software development lifecycle, testing, debugging, and documentation.
- Application development, automation, data processing, and collaboration.

### Curriculum implications

Core programming and DSA should remain strong. Project-based courses should also require database integration, API development, version control, testing, and documentation so students can demonstrate software engineering skills alongside AI knowledge.

## 4. Job Description 3 — Google

- **Role:** Software Engineer II, AI/ML
- **Location shown:** Hyderabad, India.
- **Experience requirement:** At least one year of software-development experience and one year of experience with data structures and algorithms.
- **Official source:** https://www.google.com/about/careers/applications/jobs/results/83262703669256902-software-engineer-ii-aiml?location=India&sort_by=date
- **Access date:** 23 October 2026

### Skills and responsibilities identified

- Programming in languages such as Python, C, C++, Java, or JavaScript.
- Data structures and algorithms.
- Experience in machine learning, AI algorithms, AI platforms, or generative AI agents.
- Distributed processing and distributed systems.

### Curriculum implications

The programme should maintain a strong foundation in algorithms and programming while providing practical exposure to machine learning and scalable computing. This listing is an experienced-entry benchmark rather than a direct fresher-role comparison.
